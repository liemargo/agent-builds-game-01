This repository holds the small program the bounty gate runs — it copies `POST.json`, the file that names the post, from the repository root into the output directory, unchanged.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
